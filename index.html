連線同步：問題與取捨

連線不同步是開發中花最多時間處理的問題。我透過權限控管、狀態傳遞與實際遊玩，持續降低問題發生率。

  1. 01

    問題

    雙客戶端同時操作場景物件時，位置延遲、跳動與碰撞結果會影響合作體驗。

  2. 02

    處理方式

    本機角色負責送出狀態；遠端接收位置後修正差距，物件操作前先要求控制權。

  3. 03

    限制

    受網路品質與物理更新影響，仍可能出現短暫誤差，因此以降低不同步發生率為目標。

        line.endColor = penColor;

    {
        isDrawing = true;
    };
    inputMaster.Player.UsingSkill.canceled += _ =>
    {
        isDrawing = false;

    inputMaster.Player.Left.performed += _ =>

  1. 01

Artist / NetworkPlayer.cs遠端位置接收與差距修正
public void Update()
{
    if (photonView.IsMine)
        return;
    var LagDistance = RemotePlayerPosition - transform.position;
    if (LagDistance.magnitude > 5f)
    {
        transform.position = RemotePlayerPosition;
        LagDistance = Vector3.zero;
    }
    LagDistance.y = 0;
    if (LagDistance.magnitude < 0.11f)
    {
        Player.moveSpeed = 0;
    }
    else
    {
        Player.moveSpeed = LagDistance.normalized.x;
    }
}
public void OnPhotonSerializeView(PhotonStream stream, PhotonMessageInfo info)
{
    if (stream.IsWriting)
    {
        stream.SendNext(transform.position);
    }
    else
    {
        RemotePlayerPosition = (Vector3)stream.ReceiveNext();
    }
}

private void OnTriggerEnter(Collider other)
{
    PhotonView photonView = other.GetComponent<PhotonView>();
    if (photonView != null && photonView.IsMine == false)
    {
        return;
    }
    if (hasTarget == true)
    {
        if (other.gameObject.CompareTag("Player"))
            PV.RPC("RPC_Artist", RpcTarget.All, TargetPosition);
        if (other.gameObject.CompareTag("Player2"))
            PV.RPC("RPC_Coder", RpcTarget.All, TargetPosition);
    }
    else
    {
        if (other.gameObject.CompareTag("Player"))
            PV.RPC("RPC_Artist", RpcTarget.All, transform.position);
        if (other.gameObject.CompareTag("Player2"))
            PV.RPC("RPC_Coder", RpcTarget.All, transform.position);
    }
}
